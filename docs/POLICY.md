# 현재 정책과 미확정 사항

이 문서는 확인된 구현·기존 명시 정책과 추가 결정이 필요한 항목을 구분한다.
현재 구현을 모두 승인된 정책으로 간주하지 않는다.

## 이번 작업에서 유지하는 기준

- PostgreSQL 단일 DB, forward-only 마이그레이션, 기존 시드 페르소나 유지.
- 점수 기준 L1~L5 경계는 기본 25/50/75/90이며 민감도는 점수에 반영.
- confidence는 진단 정보이며 레벨을 변경하지 않는다 (`CONTRIBUTING.md`).
- 023 마이그레이션의 명시 정책: 강력범죄·조직범죄·국가안보 직무도
  야간 `ENV_NIGHT_TIME` 배율 1.0 적용. 기본값은 15점.
  이번 변경은 과거 016 시드의 감산을 기대하던 테스트만 이 기준에 맞춘다.
- 범용 multiplier 기능과 복수 범주 중 최솟값 선택 규칙은 유지.
- 담당 등록, 유효기간이 있는 자료 접근 승인, Break-Glass는 별도 권한.

## 미확정 / 검증 대기 / 별도 수정 필요

| 항목 | 현재 확인한 상태 | 필요한 결정·작업 |
| --- | --- | --- |
| L3/L4 본문 | 인증·승인 전 미리보기 없음으로 확정 | 아래 본문 공개 정책에 따라 서버·화면 적용, 통합 검증 대기 |
| 담당 등록 OTP | 화면과 서버의 승인 가능 상태가 다름 | OTP 필수 상태 전이 확정 및 공통 집행 |
| 응답 최소화 | 주요 상세·평가 경로에 축약 함수 미연결 | 사용자·관리자 공개 필드 구분 |
| 다운로드·복사 | 현재 시도는 자기 점수에서 제외. 최근 5분 시도는 유형별 가산 | 격리 DB API·화면 최종 통합 검증 대기 |

위 항목은 배포 자동화 추가로 해결되지 않는다. 점수·본문 공개·인증 조건을
바꾸는 작업은 별도 정책 합의와 관련 테스트가 필요하다.

## 문서 본문 공개 정책

- 사건 목록은 탐색용 메타데이터만 반환한다. 담당 여부와 관계없이 `content`와
  `description`을 조회·응답하지 않고, 화면에는 상세 접근 평가 후 설명을 볼 수
  있음을 안내한다.
- 최종 결정이 L3(재인증 필요) 또는 L4(관리자 승인 필요)이면 미리보기를
  허용하지 않는다. 상세 조회와 다운로드 평가 응답의 `resource`에서
  `content`·`description` 필드를 제외한다. `can_view=false`와 실제 반환 필드가
  일치해야 한다. 상태 조회에는 어느 레벨에서도 두 필드를 싣지 않는다.
- L3의 유효한 재인증 후 또는 L4의 유효한 관리자 승인 후 최종 결정이
  L1/L2로 바뀌면 상세 응답에서 설명과 본문을 반환한다. L2의 다운로드·복사는
  기존 권한대로 거부하며, L1에서만 원본 파일 다운로드와 명시적 복사를 허용한다.
  승인 만료·권한 하락 시에는 다시 인증·승인 전 기준을 적용한다.
- 화면은 목록 설명을 본문처럼 미리 보여주지 않으며, 상태 조회에서 열람 권한이
  사라지면 이전에 저장한 본문·설명을 제거한다. 서버 응답이 권한 판단의 기준이다.

## 다운로드·복사 행동 위험도

- 현재 다운로드·복사 요청은 해당 요청의 점수에 가산하지 않는다. 접근 평가가
  완료되어 `access_logs`에 남은 이전 5분의 시도만 다음 요청부터 반영한다.
- 허용과 정책 거부를 모두 시도로 센다. 인증 실패나 평가 전 오류는 접근 결정
  기록이 없으므로 세지 않는다. 허용된 파일 응답 뒤 전송 성공이나 브라우저의
  클립보드 쓰기 성공까지 서버가 확인했다는 뜻은 아니다.
- 이전 다운로드가 1회 이상이면 `BEH_DOWNLOAD_SENSITIVE`, 이전 복사가
  1회 이상이면 `BEH_COPY_ATTEMPT`를 각각 한 번 가산한다. 기본값은 유형별
  20점이며 정책 임계값 설정을 따른다. 같은 유형의 추가 시도는 이 항목을
  중복 가산하지 않지만 기존 전체 접근 횟수 기준 고빈도·대량조회 평가는 유지한다.
- 자동 상태 조회는 `access_logs`를 만들지 않으므로 시도 횟수에 포함하지 않는다.
  명시적 복사 버튼은 서버 평가를 통과한 경우에만 본문을 받는다. 브라우저의
  기본 선택·단축키 복사는 완전히 관측하거나 차단할 수 없는 부분 구현이다.
- 총 위험점수, 점수 기준 레벨, 승인·Break-Glass 등 예외 적용 후 최종 레벨을
  분리해 유지한다. 이 정책은 기존 결정 경계나 예외 권한을 변경하지 않는다.

## 설치 및 데이터 보존

현재 설치기는 기존 설치 폴더를 교체하며 이전 폴더를 삭제한다.
데이터 보존형 업데이트가 아니다. Release 초안의 설치 검증은 기존 데이터가
없는 별도 Windows 환경에서 수행한다. 자동화가 운영 DB를 초기화하지 않는다.
