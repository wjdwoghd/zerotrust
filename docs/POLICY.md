# 현재 정책과 미확정 사항

이 문서는 확인된 구현·기존 명시 정책과 추가 결정이 필요한 항목을 구분한다.
현재 구현을 모두 승인된 정책으로 간주하지 않는다.

## 이번 작업에서 유지하는 기준

- PostgreSQL 단일 DB, forward-only 마이그레이션, 기존 시드 페르소나 유지.
- 점수 기준 L1~L5 경계는 기본 25/50/75/90이며 민감도는 점수에 반영.
- confidence는 진단 정보이며 레벨을 변경하지 않는다 (`CONTRIBUTING.md`).
- 023 마이그레이션의 명시 정책: 강력범죄·조직범죄·국가안보 직무도
  야간 `ENV_NIGHT_TIME` 배율 1.0 적용. 기본값은 15점.
  이번 변경은 과거 016 시드의 감산을 기대하던 테스트만 이 기준에 맞춘다.
- 범용 multiplier 기능과 복수 범주 중 최솟값 선택 규칙은 유지.
- 담당 등록, 유효기간이 있는 자료 접근 승인, Break-Glass는 별도 권한.

## 미확정 / 별도 수정 필요

| 항목 | 현재 확인한 상태 | 필요한 결정·작업 |
| --- | --- | --- |
| 담당 등록 OTP | 화면과 서버의 승인 가능 상태가 다름 | OTP 필수 상태 전이 확정 및 공통 집행 |
| 응답 최소화 검증 | 사건 자료 API의 서버 응답과 화면 연결을 수정 | 격리 DB API 회귀·실제 화면 실증 대기 |
| 다운로드·복사 | 접근 점수 계산에서 현재 시도 가산 제외 | 누적 행동과 현재 동작 평가 의도 정리 |

위 항목은 배포 자동화 추가로 해결되지 않는다. 점수·본문 공개·인증 조건을
바꾸는 작업은 별도 정책 합의와 관련 테스트가 필요하다.

## 일반 사용자 상태 응답 범위

### 사건 자료 API (2026-10-04 확정)

- 일반 사용자와 관리자가 **일반 사건 API**를 호출하면 동일한 최소 응답을 받는다.
  내부 점수, 4축 내역, 기본·최종 레벨, 예외 규칙·사유, anomaly·policy 근거는
  반환하지 않는다. 관리자는 기존 권한 검증을 거친 감사 경로에서 근거를 확인한다.
- 사건 목록은 접근 평가 전 단계이므로 `id`, `title`, `is_assigned_case`만
  제공한다. 사건번호·설명·등급·자료유형·부서·승인 플래그는 목록에 포함하지
  않는다. 따라서 목록의 등급 필터도 제공하지 않는다.
- 상세 평가는 `request_id`, `status` (`ALLOW`/`VERIFY`/`DENY`),
  `external_message`, 허용 행동 `actions`, `resource`를 제공한다. 재인증·자료
  접근 승인 전과 거부 상태의 `resource`는 `id`, `title`만 포함한다. 열람이
  허용된 상태에서만 사건번호·등급·자료유형·부서·본문·워터마크를 제공한다.
  설명과 DB 내부 필드는 허용 후에도 제외한다. 허용 뒤에도 다운로드 권한은
  별도로 판단한다.
- `actions`는 열람·다운로드·복사·인쇄 허용 여부와 재인증·승인 요청·긴급
  접근 시도·긴급 접근 해제 안내만 포함한다. 긴급 접근 시도 안내는 실제
  발동 허가가 아니며 발동 API가 조건을 다시 검사한다.
- 상태 조회와 다운로드 평가 POST에는 `resource`를 포함하지 않는다. 파일
  다운로드는 서버가 새로 평가해 허용할 때만 본문 파일을 반환하며, 거부
  응답에는 공개 상태·행동 권한과 오류 코드만 포함한다. 상태 폴링은 접근
  행동 횟수를 올리지 않으며, 권한 하락 시 화면에 보관된 본문을 비운다.
- 비담당 사건 클릭 기록 API는 기록 여부만 반환한다. 클릭 횟수와 행동
  위험 가산값은 감사 기록과 서버 평가에만 사용한다.

- 담당 등록 요청의 생성·중복·내 요청 조회·OTP 확인 응답은 요청 ID,
  자료 ID, 처리 상태만 제공한다. 내 요청 조회에는 화면에 표시할 제목을 더한다.
  사건번호, 등급, 검토자, 사유 및 내부 처리 시각은 포함하지 않는다.
- 본인 Break-Glass 발동·활성 조회는 발동 ID, 범위, 자료 ID, 최소 등급,
  만료 시각, 상태만 제공한다. 정당화 사유와 세션·접속 정보는 감사 경로에 남긴다.
- 인증 전 로그인 승인 상태 폴링은 상태와 승인 시 만료 시각만 제공한다.
  요청 ID와 처리 시각은 포함하지 않는다.
- `/api/auth/me`는 화면의 사용자 식별·역할·표시 점수와 세션 잔여 시간만
  반환한다. 등록 기기·허용 위치·담당 사건과 세션 접속 이력은 포함하지 않는다.
- 관리자 감사·검토 API의 공개 범위와 인증·승인 조건은 이번 변경 대상이 아니다.

## 설치 및 데이터 보존

현재 설치기는 기존 설치 폴더를 교체하며 이전 폴더를 삭제한다.
데이터 보존형 업데이트가 아니다. Release 초안의 설치 검증은 기존 데이터가
없는 별도 Windows 환경에서 수행한다. 자동화가 운영 DB를 초기화하지 않는다.
