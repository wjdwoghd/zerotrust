# 현재 정책과 미확정 사항

이 문서는 확인된 구현·기존 명시 정책과 추가 결정이 필요한 항목을 구분한다.
현재 구현을 모두 승인된 정책으로 간주하지 않는다.

## 이번 작업에서 유지하는 기준

- PostgreSQL 단일 DB, forward-only 마이그레이션, 기존 시드 페르소나 유지.
- 점수 기준 L1~L5 경계는 기본 25/50/75/90이며 민감도는 점수에 반영.
- confidence는 진단 정보이며 레벨을 변경하지 않는다 (`CONTRIBUTING.md`).
- 023 마이그레이션의 명시 정책: 강력범죄·조직범죄·국가안보 직무도
  야간 `ENV_NIGHT_TIME` 배율 1.0 적용. 기본값은 15점.
  이번 변경은 과거 016 시드의 감산을 기대하던 테스트만 이 기준에 맞춘다.
- 범용 multiplier 기능과 복수 범주 중 최솟값 선택 규칙은 유지.
- 담당 등록, 유효기간이 있는 자료 접근 승인, Break-Glass는 별도 권한.

## 미확정 / 별도 수정 필요

| 항목 | 현재 확인한 상태 | 필요한 결정·작업 |
| --- | --- | --- |
| L3/L4 본문 | 아래 공개 범위로 서버 응답 수정, DB 시나리오 검증 대기 | 격리 DB에서 인증·승인 전후 API 회귀 확인 |
| 담당 등록 OTP | 화면과 서버의 승인 가능 상태가 다름 | OTP 필수 상태 전이 확정 및 공통 집행 |
| 응답 최소화 | 자료 API는 아래 범위로 축약, 다른 사용자 API는 미검토 | 후속 작업에서 나머지 응답 경로 점검 |
| 다운로드·복사 | 접근 점수 계산에서 현재 시도 가산 제외 | 누적 행동과 현재 동작 평가 의도 정리 |

위 항목은 배포 자동화 추가로 해결되지 않는다. 점수·본문 공개·인증 조건을
바꾸는 작업은 별도 정책 합의와 관련 테스트가 필요하다.

## 자료 API 공개 범위 (이번 작업)

- `can_view=false`이면 목록·상세·상태·다운로드 판단 응답에 본문,
  설명, 사건번호, 부서, 첨부 내용이 없다. 상세 응답에는 자료 ID,
  제목, 민감 등급, 최종 레벨·요구 조치, 행동 허용 여부, 요청 ID만 제공한다.
  목록은 사건번호를 모두 제외하고, 비담당 사건의 등급 마스킹을 유지한다.
- `can_view=true`인 상세 응답에만 설명과 본문을 넣는다. 상태 조회와
  다운로드 판단 응답은 허용 상태여도 본문을 넣지 않는다. 파일 API는
  매 요청 다운로드 권한을 다시 평가하고 허용된 경우에만 원문을 전송한다.
- 일반 자료 API에는 위험 점수, 축별 점수, 내부 판단 근거를 포함하지 않는다.
  관리자용 감사 경로는 기존 권한 검사를 거쳐 상세 점수를 제공한다.
- OTP 재인증은 기존 세션 TTL 동안만 L3를 열고, 관리자 자료 승인은
  기존 유효기간과 `download_allowed` 범위에서만 L4를 연다. 만료되거나
  승인 행이 취소 상태가 되면 다음 요청에서 다시 차단한다. 점수·TTL·
  승인자 및 자기 승인 규칙은 변경하지 않는다.
- 일반 승인에 대한 취소 API는 현재 없다. 취소 상태를 설정하는 운영 경로와
  실제 화면 동작은 별도 확정이 필요하다.

## 설치 및 데이터 보존

현재 설치기는 기존 설치 폴더를 교체하며 이전 폴더를 삭제한다.
데이터 보존형 업데이트가 아니다. Release 초안의 설치 검증은 기존 데이터가
없는 별도 Windows 환경에서 수행한다. 자동화가 운영 DB를 초기화하지 않는다.
